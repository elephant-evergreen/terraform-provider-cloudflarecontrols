# cloudflarecontrols_spend_policy (Resource)

Manage a spending limit or notification for Workers or Durable Objects. An enabled usage block can interrupt product operations across the account.

## Set a spending threshold

Use an account credential with **Account → Billing → Edit**. Import and
refresh only need **Account → Billing → Read**.

```terraform
resource "cloudflarecontrols_spend_policy" "workers_alert" {
  account_id         = "00000000000000000000000000000000"
  name               = "Workers spend alert"
  product_id         = "workers"
  action             = "notification"
  enabled            = true
  threshold_cents    = 2500
  notification_email = "billing@example.com"
}
```

Start with `notification` to receive alerts. To pause supported operations
when the threshold is reached, set `action = "usage_block"`. Each product can
have one enabled block across the account. The amount is in USD cents for the
current subscription billing period. Metering delays and charges outside the
policy can make the invoice exceed the threshold.
[Cloudflare spending limits](https://developers.cloudflare.com/billing/manage/spend-management/)

## Import an existing policy

Use `cf billing spend-policies list` to find the policy ID, then inspect
its settings in [the Cloudflare CLI](https://developers.cloudflare.com/billing/manage/spend-management/cli/#list-and-inspect-policies).
Set the example arguments to match, then run:

```sh
terraform import cloudflarecontrols_spend_policy.workers_alert ACCOUNT_ID/POLICY_UUID
terraform plan
```

Expect no changes. If an enabled block already exists, import its ID.
If Cloudflare reports a version conflict, create a fresh plan and review the
current settings. Deleting a policy releases any block it holds. Use a
[removed block](https://developer.hashicorp.com/terraform/language/block/removed)
with `destroy = false` to stop managing it while keeping the policy in Cloudflare.

## Upgrade from 0.0.1-alpha.1

Remove any references to the read-only `version` attribute, then run
`terraform init -upgrade` and plan with refresh enabled. The provider keeps
the policy ID and settings and refreshes the version it uses to detect
concurrent edits.

## Schema

### Required

- `account_id` (String) Cloudflare account ID. Changing it replaces the policy.
- `action` (String) usage_block stops supported operations. notification sends an email.
- `enabled` (Boolean) Whether Cloudflare evaluates the policy.
- `name` (String) Display name, 1–200 bytes after trimming whitespace.
- `product_id` (String) workers or durable_objects.
- `threshold_cents` (Number) Positive spend threshold in USD cents. The period is the product billing period.

### Optional

- `notification_email` (String, Sensitive) Bare recipient address. Required for notification.

### Read-Only

- `id` (String) Spend policy UUID.
