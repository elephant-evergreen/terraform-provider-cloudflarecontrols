## Upgrade notes

The spend policy resource now keeps its concurrency version in provider
private state. Remove any references to the former read-only `version`
attribute. Use a plan with refresh enabled to pick up the current version.
Existing policy IDs and settings are preserved by the state upgrade.

The provider protocol tests verify the previous state format, refresh,
optimistic concurrency on updates, and deletion. They use a synthetic
Cloudflare API.
