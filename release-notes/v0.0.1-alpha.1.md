## Upgrade notes

This is the first prerelease. Set `version = "= 0.0.1-alpha.1"` to install
it explicitly. Import existing spend policies or account tokens to adopt
them. Use a Terraform state move for a supported Cloudflare account token
when its existing value must follow the resource.

## Highlights

- Manage billing-period spending thresholds and email notifications for
  Workers and Durable Objects.
- Issue account API tokens with declarative policies, expiry, and IP conditions.
